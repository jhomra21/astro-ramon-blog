I'm Juan Martinez, a software engineer. I write TypeScript, mostly with SolidJS and React, and I deploy most of my projects on Cloudflare.

## Work

From 2025 to 2026 I spent six months as a software developer at Diffusion Studio, working on their browser video editor. I moved its UI from React to SolidJS and built panels and controls from Figma designs with Tailwind CSS and Kobalte. I also built the project and template dashboards, the account, preferences, and billing screens, and the prompt controls for picking a model and adding image and video references.

One of my fixes there made asset deletion wait until IndexedDB finished saving before the editor removed the item and reported success. Another added undo and redo for replacing and removing fills without losing a video's trim.

From 2019 to 2020 I was a student web development assistant in the IT web development office at the University of Texas Rio Grande Valley (UTRGV). I built pages across utrgv.edu with faculty, and I wrote Velocity and Java templates so faculty could create and edit their own pages.

## Projects

On my own I build developer tools, real-time web apps, and native apps. A few recent ones:

- [PostJr](/blog/postjr/) is a social media scheduler that people use from the web app and AI agents use through MCP.
- [Live DAW Engine](/blog/daw-browser-convex/) is a DAW with a SolidJS editor in the browser and an Electron desktop app that hosts VST3 plugins.
- [GPUix Solid](/blog/gpuix-solid/) connects Solid 2 to GPUI, the GPU-rendered UI framework behind the Zed editor.
- [MACROS](/blog/macros-monorepo/) is an iPhone calorie and macro tracker that works without an account.

The [projects page](/projects) lists the rest.
