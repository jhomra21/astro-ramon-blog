robot-heads-solid ports [Fayaz Ahmed's robot-heads React library](https://github.com/fayazara/robot-heads) to Solid. It draws an animated TV-headed robot on a 2D canvas. The LED face follows the `state` prop, so an agent interface can show whether it is thinking, searching, listening, speaking, or in error.

## States and shapes

The component takes nine states: `idle`, `thinking`, `searching`, `listening`, `speaking`, `working`, `happy`, `error`, and `sleeping`. Each state has its own face, head motion, and antenna light. Switching states plays a short glitch and cross-fade.

Four outlines are available: `rectangle` (the default), `square`, `circle`, and `hexagon`. Every shape shares the same screen, ears, antenna, and motion.

```tsx
import { RobotHead } from 'robot-heads-solid';

<RobotHead state="thinking" size={160} />
```

## Solid 1 and Solid 2

The default entry supports Solid 1.9 and later. Solid 2 has its own entry, `robot-heads-solid/solid2`, and it is a prerelease. The package checks it against a Solid 2 release candidate, not a stable release. Do not import both entries into one application.

## Behavior

- With `interactive` on (the default), the head and eyes follow the pointer, and a click makes it hop and spin.
- With `prefers-reduced-motion: reduce`, `paused`, or a speed of `0`, the component draws the still pose for the current state.
- The canvas has `role="img"` and an `aria-label` that names the state. Pass your own `aria-label` to replace it.
- Every head on a page shares one animation loop, which pauses while the tab is hidden.

## Drawing

The shell is 3D geometry projected onto Canvas 2D, with no WebGL: a rolled-edge body, knob ears, and a spring antenna that whips when the head hops or lands. Each frame projects the shell and lights it with a key light, a fill, a sky dome, and clear-coat reflections. The LEDs fill the screen, and a bloom pass gives them their glow.
